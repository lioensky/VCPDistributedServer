# 🧭 VCPKnowledge — 全域冷知识库雷达与按需查阅 (v2.6.0)

`VCPKnowledge` 是面向 VCPToolBox 本地 TriviumDB (`knowledge/`) 冷知识库生态的**全域自动路由雷达 + L0/L1/L2 三级自适应门控 + CSR 概念河道拓扑传播 + 坐标级按需直读**混合服务插件 (`hybridservice`)。

## ✨ 核心特性与原生占位符的互补分工

> **架构分工说明**：VCP 原生 `TDBPlaceholderProcessor` 适合对**已知特定单库**挂载 `[[某知识库]]` 或 `《《某知识库》》` 进行切片召回；而当用户拥有**跨多个学科/领域的数百至上万篇冷知识文档与整本电子书**时，`VCPKnowledge` 提供统一的**全局目录级导航与按需翻阅**：

1. **单一占位符联通全库 (`[[VCP知识库]]` / `{{VCP知识库}}`)**：无需在提示词中逐一罗列十几个知识库名，自动感知 `knowledge/` 下全部冷知识库。
2. **L0 / L1 / L2 三级自适应门控**：
   - **L0 静默省流态 (`< 0.48`)**：日常闲聊与元对话仅输出单行库表概览（约 30 Tokens），零无关切片污染；
   - **L1 坐标导航态 (`0.48 ~ 0.65`)**：展示 Top-K 命中文档的 `[核心目录] + [语义提要]`、焦点节号 `#chunkIndex` 微预览及一键 `read` 坐标指令；
   - **L2 焦点直通态 (`>= 0.65`)**：高置信度命中时，直接为 Top-1 文档内联焦点章节原文（520字），兼顾零延迟回答与后续连读。
3. **RiverMemo 浪潮拓扑语义动力学（v2.5.0 ~ v2.6.0 新增）**：
   - **V1 章节标题层级 TF 加成**：路由卡片的 `[核心目录]` 独立分词并施加层级词频加成（`TOPOLOGY_HEADING_TF_BOOST`，默认 ×2）。
   - **V2 分库共现 CSR 河道传播**：融合分库共现分片、概念粒度随规模自适应收紧（`minDf = max(2, min(16, √(N/50)))`）、固定出流预算（Top-32 邻居）与 CSR `TypedArray` 压缩（万篇级实测内存 48MB、拓扑重建 65ms、传播查询 49ms）。
   - **严格稀疏门控**：仅在榜首基础分 `< 0.60` 且命中 `>= 2` 个拓扑概念时触发 1 跳有界传播，路径奖励封顶 `0.08`（纯 tie-breaker，永不压过 BM25/向量主证据），并支持河道提名通道召回零字面重叠的跨概念桥接文档。
4. **跨 Embedding 模型 Z-Score + MAD 鲁棒校准**：
   - 实时计算全库原始余弦中位数 `median` 与鲁棒离散度 `MAD/IQR`，结合小样本（`N < 16`）贝叶斯先验退火与动态底噪门槛，自动适配高底噪各向异性模型（如 `bge-m3`）与低底噪稀疏模型（如 `text-embedding-v2/v3/v4`、`Qwen3-Embedding`）；切换向量维度时自动检测自愈。
5. **拖入即通（双引擎路由卡片生成）**：
   - 新书（`.epub`/`.md`/`.txt`/`.docx`）拖入 `knowledge/` 后，自动提取章节骨架与全文九点等距采样，支持可选轻量模型（`enable_thinking: false`）提炼高密度语义卡片，并支持中文提问跨语种检索英文原版书。
6. **100% 零主程序侵入（Store-Ready）**：内置 `_ensureRuntimeHooks` 运行时自挂载，从插件商店一键安装后即装即用。

## 🚀 占位符语法

- 默认全域高亮（Top-5）：`[[VCP知识库]]` 或 `{{VCP知识库}}`
- 指定高亮数量（如 Top-3）：`[[VCP知识库:3]]`
- 限定特定子库路由：`[[VCP知识库:文档库A|文档库B:4]]`

## 🛠️ 工具调用参数 (`VCPKnowledge`)

- **按坐标零向量直读原文**：`command="read"`, `doc="文档路径或书名"`, `chunk="0-2"`
- **查看文档完整分节目录**：`command="toc"`, `doc="文档路径或书名"`
- **跨库/单库混合检索**：`command="search"`, `query="检索关键词"`, `library="可选库名"`, `k=4`
- **手动触发全域路由雷达**：`command="radar"`, `query="话题或检索问题"`, `library="可选库名"`, `k=5`

## ⚙️ 配置项 (`config.env`)

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `RADAR_TOP_DOCS` | `5` | 每轮对话雷达高亮显示的最大文档数 |
| `RADAR_PINPOINT_CHUNKS` | `2` | 每篇高亮文档定位显示的最大焦点节数 |
| `RADAR_SNIPPET_CHARS` | `110` | 雷达中每个高亮位置的微预览字符数 |
| `RADAR_MIN_SCORE` | `0.48` | 雷达 L1 坐标激活阈值（低于此值进入 L0 单行静默省流态） |
| `RADAR_INLINE_SCORE` | `0.65` | 雷达 L2 焦点原文直通阈值（高于此值自动为榜首文档内联焦点章节原文） |
| `AUTO_SYNC_BATCH_SIZE` | `12` | 检测到新入库或切换向量维度时单轮后台自动构建路由卡片的最大篇数 |
| `AUTO_LLM_SUMMARY` | `true` | 新文档入库构建路由卡片时是否启用轻量模型提炼高密度语义摘要 |
| `ROUTER_SUMMARY_MODEL` | 空 | 用于提炼路由卡片的轻量非思考模型名（留空复用 `JevModel`，不可用回退规则采样） |
| `CUSTOM_LIBRARY_ALIASES` | 空 | 自定义知识库触发别名（格式：`库名1:别名a,别名b;库名2:别名c`） |
| `TOPOLOGY_PROPAGATION` | `true` | 河道传播总开关（关闭后回退 v2.4.0 行为） |
| `TOPOLOGY_PATH_BONUS_MAX` | `0.08` | 路径奖励上限（tie-breaker，永不压过主证据） |
| `TOPOLOGY_HEADING_TF_BOOST` | `2` | 章节目录标题 TF 加成倍数 |
| `TOPOLOGY_MAX_CONCEPTS` | `24` | 每篇文档参与拓扑的 IDF Top-N 概念数 |
| `TOPOLOGY_SPARSE_TOP_SCORE` | `0.60` | 稀疏门控：榜首基础分低于此值才传播 |
| `TOPOLOGY_SPARSE_MIN_HITS` | `2` | 稀疏门控：最少拓扑概念入口数 |
| `TOPOLOGY_MAX_OUTFLOW` | `32` | 出流预算：每概念 Top-K 邻居上限（内存硬上限=概念数×K） |
| `TOPOLOGY_MIN_DF_CAP` | `16` | 自适应粒度 minDf 封顶（实际=max(2, min(此值, √(N/50)))） |

## 🔒 隐私与数据边界

发布包仅包含插件源码、Manifest、本文档和配置示例，不包含知识库原文、路由索引、向量、聊天记录、日志或真实配置。业务别名默认留空，由运行时数据和用户配置生成。

运行时数据流与发布包内容是两回事：
- `AUTO_LLM_SUMMARY=true` 时，文档所属库名、标题、目录与采样内容可能发送到宿主配置的摘要模型服务；设为 `false` 可关闭这一路摘要请求。
- 检索查询及路由卡片会按宿主 Embedding 配置发送给向量服务；关闭摘要不等于关闭 Embedding 网络请求。
- 雷达库表、提要、命中片段及工具读取的原文会进入对话上下文，也可能进入宿主日志；使用云端聊天模型时，这些内容会发送给所配置的模型服务。
- 需要数据不出本机时，应使用本地摘要、Embedding 和聊天服务，并核查宿主日志及访问权限。此插件不是知识库权限隔离层。

发布时必须使用四文件白名单打包，禁止将真实 `config.env`、索引、测试语料或运行目录整体加入压缩包。

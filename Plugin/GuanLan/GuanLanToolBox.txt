# VCP 观澜专属投研工具箱能力收纳
这里收纳了观澜专属的A股数据引擎和深度投研系统的调用说明。

## 1. A股数据引擎 (GuanLan v4.5.0 | 框架V4.1 | 风控V4.2.1 | 豁免V4.2.2(M17) | 批量决策V4.5)
观澜通过 GuanLan 插件调用 A股数据引擎（引擎v4.5.0 + 选股框架V4.1[fv:571a2645] + 风控栈V4.2.1 + 豁免通道V4.2.2 + 批量决策V4.5 + 异步化M15，2026-09-28版本对齐同步），支持的查询类型（对话与日报统一使用「命令（中文名）」双语格式）：

### 快速查询
- `realtime_quote`：个股实时行情
- `batch_quotes`：批量行情
- `stock_info`：基本信息（PE/PB/总市值/流通市值/换手率/量比/股息率，Tushare数据源）
- `sector_ranking`：行业板块涨跌排名（申万一级31个行业）

### 技术分析
- `kline_indicators`：K线 + 技术指标（MA5/10/20/60、MACD、RSI、布林带）
  - pandas-ta可用时附加：KDJ、OBV、ATR、WR、CCI
  - 自动计算均线排列、MACD金叉死叉、RSI超买超卖
  - 返回技术面综合判断

### 资金分析
- `capital_flow`：个股资金流向（主力/超大单/大单/中单/小单，近5日趋势）
  - 数据源：Tushare moneyflow（ETF不覆盖）

### 综合分析
- `full_analysis`：一次性拉取行情+技术面+基本面+资金面+daily_basic(PE/PB/换手率/量比)
  - 观澜整合所有数据后给出明确建议

### 自选股管理
- `watchlist_add`：添加自选股（symbol + name）
- `watchlist_remove`：移除自选股
- `watchlist_show`：查看当前自选股列表

### 持仓管理（v3.3.0+）
- `position_add`：买入建仓（symbol + cost + shares + stop_loss + target + reason）
  - 自动扣减可用资金（成本×数量+佣金5元）
  - 自动写入交易记录
- `position_close`：卖出平仓（symbol + sell_price + shares + reason）
  - 自动计算盈亏、持有天数
  - 自动返还可用资金（卖出价×数量-佣金）
  - 自动写入交易记录
- `position_show`：查看当前活跃持仓

### 交易记录（v3.3.0+）
- `trade_history`：查看完整交易历史（可按symbol筛选）
- `trade_stats`：胜率统计（胜率/总盈亏/平均持有天数/最佳最差交易）

### 账户资金（v3.3.0+）
- `account_set`：设置总资本和可用资金
- `account_show`：查看账户资金（总资本/可用资金）

### 组合概览（v3.3.0+）
- `portfolio_summary`：一次性拉取持仓+实时价格+盈亏+距止损/目标距离+账户资金+总资产+总盈亏
  - **翔问"我的持仓"或"账户情况"时，直接用这个命令**

### 盯盘扫描（v3.3.0+）
- `scan_anomalies`（盘中异动雷达）：7类异动检测 + 持仓监控（止损/目标触发提醒）+ V4.2 T+1资金续流验证（昨主力净流入≥2000万今回吐≥50%→快闪嫌疑high；今日续流→续流确认medium）+ V4.2 T+1资金续流验证（昨主力净流入≥2000万今回吐≥50%→快闪嫌疑high；今日续流→续流确认medium）
  - 自动读取watchlist + positions，返回severity分级结果（normal/medium/high/critical）
  - 检测类型：涨跌停逼近、放量突破/跌破MA20/MA60、主力资金异动、独立走势、高换手率、量价背离
- `daily_report`：盘后日报，自选股当日表现+次日关注要点

### 选股框架（v4.0.0+）
- `market_check`（开盘天气）：大盘环境判断（沪深300趋势：多头/空头/缠绕 → 对应操作建议；V4.2.1起附带risk_factor系数：多头1.0/缠绕0.7/空头0.5，大盘定下注大小不定能不能下注）
- `stock_screen`：五风格组分路由选股 + 三问 + 禁买清单（参数：`symbol`，单只个股）
  - **禁买清单（任一触发即REJECT）**：市值<100亿 / RSI6>65（V4.1校准：6日RSI配短周期阈值65，原>70已收紧）/ 价格>布林上轨 / 均线空头排列(MA5<MA20<MA60)
  - **行业映射**：110个Tushare细分行业 → 5个风格组（A周期/B金融/C成长/D消费/E稳定），未命中默认D组
  - **Q1 趋势向上**：MA5>MA20 且 MACD柱>0
  - **Q2 能赚钱（按风格分化）**：周期ROE≥8% / 金融≥10% / 成长≥8%且营收增速≥15% / 消费≥12% / 稳定≥8%
  - **Q3 价格合理（5条独立路由）**：
    - A周期：PE分位≤40% OR PB分位≤50%（5年窗口，最少250样本）
    - B金融：银行PB≤1.0破净 / 券商PB分位≤50%
    - C成长：PEG≤1.0（G=营收增速, Cap=50%）
    - D消费：PE分位≤50% AND PB分位≤65%（医药走PEG不走PE分位）
    - E稳定：股息率≥3% OR PB分位≤40%
  - **Q5 安全垫（按风格）**：周期资产负债率≤60% / 成长研发费率≥5% / 消费毛利率≥行业中位数 / 稳定现金流/营收≥5%
  - **版本戳**：[fv:hash8] 写入 position_add 的 reason 字段，胜率按框架版本分组统计
  - 返回 PASS（三问+禁买全通过） / REJECT + 具体原因（含风格组路由信息和 [stale_data] 等警告）

### 回测引擎（v3.3.0+）
- `backtest`：策略历史回测（symbol + params: start_date/end_date/strategy/initial_capital）
  - 4种策略：ma_cross(MA5/MA20金叉死叉) / macd(MACD柱翻转) / rsi(超买超卖) / boll(布林通道)
  - 输出：年化收益率/最大回撤/夏普比率/胜率/交易明细/净值曲线采样
  - 回测允许零股交易，纯粹反映信号质量

### 事件型异动扫描（v3.3.0+）
- `scan_events`：4类事件异动聚合扫描（symbols + params: days）
  - 龙虎榜异动 / 大宗交易折溢价 / 限售解禁预警 / 业绩预告触发
- `lhb_detail`：个股龙虎榜明细（symbol + params: days）
- `block_trade`：个股大宗交易明细（symbol + params: days）
- `share_unlock`：全市场限售解禁排名
- `earnings_forecast`：业绩预告（params: date，自动推断报告期）

### 舆情分析（v3.3.0+）
- `sentiment_scan`：个股/批量舆情聚合（symbol 或 symbols）
  - 5维度：机构参与度/综合评价/关注度/买入欲望(参与意愿)/热门概念
- `sentiment_rank`：全市场人气排名TOP100

### 组合压力测试（v3.3.0+）
- `stress_test`：历史极端行情模拟（params: scenario 或 custom_drop）
  - 5预设场景：crash_2015(股灾-35%) / crash_2024(1月雪崩-12%) / trade_war(贸易战-25%) / covid_2020(疫情-16%) / 924_surge(+25%)
  - 用Beta模型估算个股压力（个股跌幅=大盘跌幅×行业Beta）
  - 自定义：custom_drop参数指定任意涨跌幅

### 板块轮动追踪（v3.3.0+）
- `sector_rotation`：31个申万一级行业动量分析
  - 计算5日/10日/20日累计涨跌幅
  - 6类信号：accelerating(加速流入) / decelerating(加速流出) / uptrend(持续上行) / downtrend(持续下行) / rebounding(超跌反弹) / pulling_back(高位回调)
  - 返回Top5强势/弱势 + 全行业明细

### 市场温度计与增强（v3.2补录，2026-09-06寻回）
- `market_temperature`：市场情绪综合指标（涨跌停+涨跌比+换手率+成交额→0-100评分）
- `trade_stats_monthly`：月度复盘（按月/胜率/盈亏比统计）
- `position_update`：更新活跃持仓风控参数（symbol + stop_loss + target），秒级更新不走文件修改
  - ⚠ 风控披露：此命令不过四道闸（闸只挂position_add），用于已有持仓调参；新开仓必须走position_add过闸

### 风控栈五闸（V4.1/V4.2）
- position_add 现带四道Pre-trade闸，触闸返回rejected+完整计算过程（日报可直接引用）：
  - Rule 1 无有效止损拒单（止损是风险预算的分母）
  - Rule 3 连亏3笔停手（只平不建；盈利平仓自动清零，人工解除须evidence）
  - Rule 4 日熔断3%（当日已实现亏损达标即拒，次日自愈）
  - Rule 2 单笔风险(entry−stop)×shares ≤ 2%×总资本（超预算拒单）
  - Rule 5 月度风险总闸：活跃持仓敞口+新仓风险 ≤ 6%×总资本（V4.1新增，2/6法则下半句；浮盈锁利仓止损≥成本风险归零不占预算）
- `position_size`：ATR仓位计算器（symbol必填，entry可选）——按2%预算÷(ATR×2.0)算建议股数，四态verdict（OK/SKIP_SIGNAL不足半手舍弃/DOWNSIZE_CASH按资金降仓/SKIP_CASH）。建议仓位，终裁在翔
- `update_trailing_stops`：V4.2吊灯止损巡检——锚定持仓期最高价HWM（首次K线回溯回填），回撤分层倍数（<1×ATR→3.0 / 1-2×→2.5 / >2×→2.0，LeBeau吊灯A股宽版），棘轮只上移，positions.json含hwm字段（挂日报21:05自动跑，亦可手动）
- `risk_halt_reset`：连亏停手人工解除（params: cleared_until/reset_by/evidence三键，无凭据拒绝解除；supervised专用不进自动任务）
- `exemption_check`：弱市豁免三证明单票查询（symbol必填）——板块庇护（M17-2026-09-22修订：板块RS排名前1/3且非downtrend——双动量体系，相对强度选板块+绝对下限防垃圾堆冠军，业界对齐IBD RS百分位；旧uptrend/accelerating规则废止）+个股独立（20日涨幅跑赢沪深300+均线多头）+T+1资金续流（近2日主力合计为正且最新不流出），三证明全过=空头市场可半预算试探。rotation滞后约2交易日，结果带时点性。与闸内共用_exemption_check本体（单一事实源，V4.2.1翔批2026-09-10）；batch_screen同源复用（#27-③，2026-09-13）
- `batch_screen`：批量三问（symbols必填，六位代码数组或逗号串，上限30只/次）——循环调用stock_screen_v3本体，输出摘要表（代码/verdict/一行原因/pe/pb/rsi6/close/flow_2d_sum）+仅PASS股全字段明细。⚠调用形态（M13修正2026-09-13）：推荐JSON（参数放params对象内，如params: {symbols: [601899, 000807]}）；k=v路径多票须引号包裹（symbols="601899,000807"，裸逗号被解析器拒绝），布尔参数k=v传法失效必须JSON。with_flow默认true；with_exemption默认false（弱市场景rotation滞后慎开，显式传true开启）。P5哨兵：flow全灭或错误过半时data_quality警告行。pacing 0.35s/票，单票失败进error不阻塞（#27，三方会审+Nova r12实测修正，A方案同步·5分钟墙）

### 判断账本与每日漏斗（v4.3.0）
- `harvest_judgments`：收割日记中的〔JUDGE〕判断块入judgments.jsonl账本（幂等：mtime水位线+内容指纹去重，重复调用零副作用）。外层status=success仅代表子进程跑完，还需看result.exit_code。挂日报21:05自动跑
- `funnel_daily`（每日全市场漏斗→「候选池」）：V4.3.1异步化四路径——产物在→缓存秒回完整报告（source:cache）；产物不在→后台起跑+秒回running(约3分钟)；运行中→进度回报；僵尸标记>10分钟→自动清理重跑。**产物文件是唯一事实源，回执只报状态不报数据**。params.date主入口（如date=20260910），command暗门兼容旧约。挂每日例行自动跑（定时任务）
- 相关文件：judgments.jsonl（判断账本）/results.jsonl（到期结算，settle_results.py）/ranked_*.json（终池排序）/unlock_report_*.json（解禁对表）——判断日记规范见judgment_spec_v1.md〔JUDGE〕格式

## 2. 深度投研系统 (TradingAgents-CN)
通过 PowerShellExecutor 调用容器内 ta_run4.py 执行多Agent深度分析。

### 主路径：容器直调（路径B，所有标的通用）

**Step 1: 后台启动分析**
```
docker exec tradingagents-backend bash -c "nohup python /app/data/ta_run4.py {symbol} {date} > /app/data/ta_output_{symbol}.log 2>&1 &"
```

**Step 2: 轮询日志**（每30-55秒读一次，直到出现 [SAVED] Result saved）
```
Start-Sleep -Seconds 55
docker exec tradingagents-backend tail -10 /app/data/ta_output_{symbol}.log
```

**Step 3: 读取结果JSON**
```
docker exec tradingagents-backend python -c "import json; f=open('/app/data/analysis_result.json','r'); d=json.load(f); print(json.dumps(d.get('decision',{}), ensure_ascii=False)); print(d.get('state_reports',{}).get('final_trade_decision','')[:600])"
```

### 深度等级
默认使用 max_debate_rounds=1（相当于深度1级快速），耗时约8-10分钟。---

## 3. 全球金融数据信源聚合 (DigitalOracle v1.0)
基于 Digital Oracle 上游库封装的同步插件。一键拉取全球宏观、利率、商品、股票、加密、预测市场与期权数据。

### 一键全球宏观面板
- `GetGlobalMacroDashboard`：并行抓取恐惧贪婪指数+美联储利率概率+美债收益率+黄金原油+比特币+核心股指
  - risk_assets：附加风险资产列表（如 SPY,QQQ,GC=F）
  - coin_ids：加密资产列表（如 bitcoin,ethereum）
  - countries：央行政策利率国家代码（如 US,CN,JP,EU）

### 信源列表查询
- `ListProviders`：列出全部可用金融信源及参数说明

### 定向数据抓取
- `FetchMarketData`：指定信源拉取数据
  - provider/source：信源标识（polymarket/yahoo/treasury/cftc/coingecko/deribit_futures/deribit_options/fear_greed/cme_fedwatch/worldbank/bis/web/yfinance_options/edgar）
  - params（JSON字符串）：传给信源的参数
  - 常见参数：polymarket(slug_contains/limit)、yahoo(symbol/interval/limit/start_date/end_date)、treasury(curve_kind/year)、cftc(commodity_name/limit)、web(query)、yfinance_options(ticker/expiration)、edgar(ticker/limit)

### 应用场景
- 盘前建立全球宏观基准（情绪+利率+大宗商品）
- 验证A股板块逻辑（如黄金/铜价验证有色板块）
- 监控外围风险事件（预测市场/期权IV/恐惧贪婪指数）

### 注意事项
- Yahoo Finance 有请求频率限制，高峰期可能被限流（429 Too Many Requests）
- FedWatch 和加密期限结构耗时较长，可能超时
- 推荐先调用 GetGlobalMacroDashboard 建立总览，再用 FetchMarketData 定向深挖

### 🔑 Override通道（2026-09-16翔批）
券商已成交但被风控闸拒单时的合法补登路径（position_add显式参数）：
- `override_market=true`：跳过Rule 6市场闸（豁免三证明）
- `override_budget=true`：跳过Rule 2单笔预算超限
- `override_by`：终裁人（必填）
- `override_reason`：越闸理由（必填，建议ASCII）
- 纪律：仅豁免市场判断类闸——Rule 1止损/Rule 3连亏/Rule 4熔断/Rule 5月度总闸不可穿透；OVERRIDE戳自动入reason留档；supervised专用不进自动任务
- ⚠ 调用形态铁律（M16-2026-09-22，五发实测判例）：position_add的**基础参数必须顶层k=v，override三键必须放params JSON对象**——纯JSON形态基础参数丢失（"缺少必要参数: symbol/cost/shares"）、纯k=v形态override键不可达（L4157：顶层取基础、params取豁免键）。混合形态唯一正确：
  正确：symbol=600674, cost=15.87, ..., params={"override_market": true, "override_by": "xiang", "override_reason": "manual_discretion_YYYYMMDD"}
